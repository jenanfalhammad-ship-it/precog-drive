# ORBIT — Connecting devices to a better world

منصة ORBIT الذكية لتحليل الأجهزة، تقدير قيمتها، تقييم صحتها، واقتراح الإصلاح المناسب قبل التعطل.

## ما تم بناؤه

- محلل أجهزة بالذكاء الاصطناعي: رفع صورة الجهاز ثم إظهار النوع والقيمة المتوقعة والصحة والإصلاح و **ORBIT Score**.
- مركز أجهزة افتراضية يضم الهاتف والحاسوب واللوحي والساعة مع مؤشرات اتصال وأداء وبطارية وحماية.
- فعاليات وتجارب تعليمية وتحديات ابتكار مرتبطة بالتقنية والإصلاح الذكي.
- دعم العربية والإنجليزية، RTL، الوضع الداكن والفاتح، وتصميم متجاوب.
- مسارات جاهزة للنشر مع `public/manus-routes.json` وسير عمل GitHub Pages.
